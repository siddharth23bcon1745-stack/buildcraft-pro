# BuildCraft Pro

BuildCraft Pro is a full-stack construction project management platform designed to connect customers, contractors, and administrators in one workspace.

## Features

- Construction services showcase
- Portfolio and project display
- Quick project cost estimator
- Customer, contractor, and admin dashboard interfaces
- Project management workflow
- Responsive frontend design
- Express.js backend with MongoDB integration

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
